TV Show Lab

A React-based web application that fetches and displays television show information using the TVmaze API.

Objective

To build a single-page React application that allows users to search for TV shows and view show details with proper loading and error handling.

Features

Search for different TV shows.
Fetch show information using the TVmaze API.
Built with React functional components and Hooks.
Display loading messages while fetching data.
Handle API errors gracefully.
Simple and user-friendly interface.
Technologies Used

React.js
JavaScript (ES6+)
HTML5
CSS3
Fetch API
TVmaze Public API
🔗 API Used

TVmaze Single Search API:

"https://api.tvmaze.com/singlesearch/shows?q=SHOW_NAME"

API Documentation: https://www.tvmaze.com/api

Getting Started

Prerequisites

Node.js
npm
Visual Studio Code (recommended)
Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Navigate to the project directory:

cd TV-Show-Lab

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local URL displayed in your terminal.
